# FitForLife

**FitForLife** is a fitness tracking web application built using Node.js, Express, and MongoDB. It helps users track workouts, set goals, and monitor progress in a secure and organized way.

## 🚀 Features

- User registration and login with JWT authentication
- Workout and exercise CRUD functionality
- Goal setting and progress tracking
- RESTful API with secure endpoints

## 📦 Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [MongoDB](https://www.mongodb.com/) (local or remote)
- [npm](https://www.npmjs.com/)
